# Personal Portfolio Project Overview

## Project Purpose
This is a personal portfolio website for Rick Cohen, who is a Quality Engineer & Diagnostic Tools Developer. The portfolio showcases his skills, projects, and professional experience.

## Tech Stack
- **Frontend**: React with TypeScript, Tailwind CSS
- **UI Components**: Shadcn UI components based on Radix UI
- **Routing**: Wouter for client-side routing
- **State Management**: TanStack React Query
- **Styling**: Tailwind CSS with custom theming
- **Database**: PostgreSQL with Drizzle ORM
- **Backend**: Express.js with TypeScript
- **Build Tools**: Vite for frontend, esbuild for backend

## Project Structure
- `/client`: Frontend React application
  - `/src`: Source code
    - `/components`: UI components including portfolio sections
    - `/hooks`: Custom React hooks
    - `/lib`: Utility functions and data
    - `/pages`: Main pages (Home, NotFound)
- `/server`: Backend Express application
- `/shared`: Shared code between frontend and backend
- `/attached_assets`: Static assets

## Features
The portfolio showcases:
1. Developer information and bio
2. Skills in programming, quality engineering, and tools
3. Projects with descriptions and technologies used
4. Contact information
5. Responsive design with terminal-inspired UI
